about=Loads JVF DTM files into QGIS and organizes features into layer groups. Each layer is automatically styled using predefined symbology. Files are processed in the background to keep QGIS responsive during loading. Visible layers can be exported to GeoPackage or DXF. Načítá soubory digitální technické mapy (DTM) ve formátu JVF do QGISu a organizuje prvky do skupin vrstev. Každé vrstvě je automaticky přiřazen předdefinovaný styl. Načítání probíhá na pozadí, takže QGIS zůstává během procesu plně responzivní. Zobrazené vrstvy lze exportovat do GeoPackage nebo DXF.

changelog=Version 2.0.0: Support for JVF DTM 1.5.0.2 (record elements ZaznamObjektuIns/Upd/Ref..., deleted records are not shown; to load JVF DTM 1.4.3 use an older version of the plugin), updated XSD schemas and styles including separate styles for definition points (_DB) and more symbol layer types; export of visible layers to GeoPackage (with styles, layer groups and project stored in the GeoPackage) and to DXF (scale-dependent symbology, inverted grayscale, AutoCAD 2007 / UTF-8, properties ByLayer); the layer with the second geometry of a feature is now visible after loading; documentation of the export.
	Version 1.3.0: Port to QGIS 4 / Qt6 (also works on QGIS 3.34+); replaced direct PyQt5 imports by qgis.PyQt, scoped enums, Qgis.WkbType/Qgis.MarkerShape and QMetaType for fields.
    Version 1.2.0: Background loading of files, improved zooming, layer grouping by file and updated metadata and licensing.
